# Research release archive

The complete research workspace accompanying database v30 is preserved in
[`jambu-research-v30.tar.gz`](https://github.com/aryamanarora/jambu/releases/download/db-v30/jambu-research-v30.tar.gz).
The archive includes the frozen Telugu `quantitative-2026-09-09/groups.jsonl`
file, which exceeds GitHub's 100 MB per-file Git limit and is therefore excluded
from Git. Extract the archive at the repository root to restore it at its original
path. The archive also retains a snapshot of the active Telugu blog development
server's `dev.log`, which remains untracked because it changes while the server
runs. The remaining research files are also committed here.

The release's `SHA256SUMS` records the archive and database checksums. Existing
research manifests continue to describe the original, unmodified evidence files.
